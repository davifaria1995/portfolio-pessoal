Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para apresentar minha trajetória, habilidades técnicas em desenvolvimento e os projetos práticos que estou construindo durante minha jornada na área de tecnologia.

**Acesse o projeto online:** [https://davifaria1995.github.io/portfolio-pessoal/](https://davifaria1995.github.io/portfolio-pessoal/)

Sobre o Projeto

Atualmente estou cursando Análise e Desenvolvimento de Sistemas e em transição de carreira para a área de desenvolvimento de software. Este site serve como meu cartão de visitas digital, reunindo informações sobre mim, as linguagens que estou estudando e canais diretos de contato.

Funcionalidades e Características

Design Responsivo: Adaptado para visualização em desktops, tablets e dispositivos móveis.

HTML Semântico: Estrutura organizada visando boas práticas de acessibilidade e SEO.

CSS Moderno: Utilização de variáveis CSS (:root), Flexbox e CSS Grid para layout.

Navegação Suave: Rolagem fluida (smooth scroll) entre as seções da página.

Tecnologias Utilizadas

HTML5: Estruturação semântica do conteúdo.

CSS3: Estilização, layout responsivo (Grid/Flexbox) e paleta de cores personalizada.

Como Visualizar Localmente

Acesse a pasta do projeto:

cd portfólio-pessoal


Abra o arquivo index.html diretamente no seu navegador de preferência.
